# Исправления по оригинальным моделям

Проверено по animation-audit-models.vpk, присланному 16 октября 2026. Проверка структуры и анимационных таблиц не заменяет запуск в Dota.

- Mace of Aeons: девять анимаций с тегом `mace` находятся в оружии (скелет из пяти костей), а не в модели героя. Правила применяются к заменённой модели оружия; герой не подменяется. Работает для стилей, использующих эту же модель.
- Boomerang of the Twin Blades: последовательность `twinblade_shuriken_toss_injured` имеет тег `twinblade_shuriken_toss`, а не тег, совпадающий с её именем. Исправление ограничено этой последовательностью и сохраняет условие `injured`.
- Claddish Cudgel: модель Tidehunter содержит атаку с тегом `fish_slap`; устаревший `fishstick` отсутствует. Включается только атака, не произвольные остальные действия героя.
- Fists of Axe Unleashed: оригинальная схема заменяет героя на `axe_bare` и оружие на invisiblebox. У исходного Axe 56 костей, у axe_bare — 72. Вместо переноса несовместимых дорожек используется целиком авторская модель с её скелетом, геометрией и анимациями. В предпросмотре выбирается та же модель. Отдельная стойка Unleashed без этой модели пока не добавлена.
- Каталог призванных существ: старые имена с суффиксами `_1`–`_4` могут ссылаться на существующий современный юнит без номера. Замена разрешается только при наличии этого юнита, его настоящего Model и исходной косметической модели. Путь базовой модели не угадывается.

Отсутствующие правила loadout у Obsidian Blade Warhelm, idle rare у Inverse Bayonet и Wolfhound Rifle не заменяются похожими клипами наугад. Наличие обычных idle/attack при этом учитывается. Frost Avalanche остаётся исключённой арканой; автоматическая установка этой арканы не добавлена.

Нативный патчер проверяет, что при правке activity меняются только соответствующие метки. Остальные данные ANIM/ASEQ и остальные блоки модели должны совпасть с исходными. Перенос axe_bare в базовый путь сохраняет runtime-блоки исходной модели.
