# Исправления креплений и передачи моделей в админке

Применить поверх DotaEffectStudio_Admin_Viewer_Animations_Bindings_Loading_FIX.zip. CI пересобирает runtime; workflow и публичный вивер не меняются.

- Настройки particle attachment из items_game передаются в новый вивер, включая parent/self, именованные точки и явные номера control point. Работает и для существующего статического каталога без повторной выгрузки на R2.
- Конфигурация preview имеет приоритет над первой конфигурацией партикла. Удалён поиск одноимённой точки на посторонних вещах.
- При преобразовании GLB текстурные метаданные остаются у материала и не копируются повторно в GLTFLoader. Геометрия, бинарные буферы и метаданные анимаций сохраняются.
- Приватные модели передаются с gzip при поддержке браузером. Проверка владельца/администратора выполняется перед передачей. На контрольной модели Spectre: 3262064 → 656885 байт (-80%); это не замер времени загрузки арканы.

Проверки: 600 Node-тестов; Chromium — камера по вертикали, смена вещей, кеширование, отмена старого запроса, восстановление анимации, native bone alias, настоящий Spectre GLB.

Ограничения: исходные GLB/пакеты эффектов с присланных скриншотов недоступны. Полное совпадение Ember/Void/Drow с Dota и устранение пересвета Void не подтверждены. Сжатие ускоряет передачу; первый серверный экспорт и неподдерживаемые particle operators требуют отдельной проверки на этих ресурсах.
