# Исправления подготовки ресурсов нового вивера

Этот объединённый архив уже включает Shared_Pedestal_Stance_FIX. Применить поверх Admin_Viewer_Attachments_Loading_Followup. CI пересобирает asset-bridge и runtime; отдельного ручного build не требуется. Публичный вивер и алгоритм сборки VPK не заменяются.

## Исправления

- Native snapshot weights переводятся в поле skinning, которое читает dota-loadout. Раньше перевод создавал поле skin, а в skinning оставались неподходящие объекты.
- Для snapshots без весов определяется кость по совпадению bind-pose точек и вершин модели. Алгоритм соответствует подготовке ресурсов автора; KD tree ограничивает поиск ближайших вершин. Жёсткие снимки не назначаются кости, если совпадение недостаточно хорошее.
- fx.js синхронизирован с upstream commit 3c09d200391cf19db14705dbaca0d6c544dae670: добавлен spritecard channel mixing, включая альфа-канал из яркости текстуры. Это устраняет соответствующие непрозрачные ореолы/полосы.
- Asset bridge сохраняет полные UV кадра, crop и clamp для sprite sheets; адаптер передаёт их независимо.
- Native metadata включает Dota material masks, detail, fresnel, diffuse warp, specular exponent и режимы alpha/additive/translucent. Они применяются к соответствующей вещи с сохранением исходной геометрии. Встроенные метаданные изменённой модели имеют приоритет над оригиналом из архива. Недоступные текстуры оставляют предупреждение и имеющиеся GLB-текстуры.
- Activity modifiers выбранных моделей читаются из items_game (без изменения файла). Например, arcana/ti9_totem включают соответствующие варианты анимаций. Восстановление отсутствующих клипов учитывает эти теги.
- Старые статические GLB получают material metadata через приватный серверный кеш без полного переэкспорта геометрии. Версия кеша обновляется автоматически.

## Проверка и ограничения

609 Node-тестов; C# build — 0 ошибок и предупреждений; тест сохранности GLB binary chunks; Chromium — камера, смена одежды, отмена запросов, материалы с масками/detail/exponent, анимации и пьедестал. На настоящем native Earthshaker arcana (263 sequences) выбран es_arc_idle_v2_loadout — как в reference hero.json.

Reference: https://loadout.nyan.cafe/#earthshaker/head=34382,weapon=12969,arms=7293,belt=12744,hero_base=12692 . Проверены авторские manifest JSON для арканы и тотема. Полное визуальное совпадение всего набора не подтверждено: открытый облачный браузер не создал WebGL-контекст. Локальный Chromium проверяет приложение, но не является снимком пользовательского сервера.

Snapshots, channel mixing и metadata применяются к существующим данным. Если старый static particle packet уже утратил uncropped UV/clamp при предыдущем экспорте, восстановить эти поля из обрезанных координат безопасно нельзя: для этих пакетов требуется повторная публикация эффектов обновлённым asset bridge и синхронизация R2. Полный каталог ради новых material metadata переэкспортировать не нужно. Отсутствующие модели/refits или неподдерживаемые particle operators этим патчем не создаются.
