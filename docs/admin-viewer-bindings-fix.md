# Исправления нового viewer в админке

Патч накладывается поверх Admin Full Set Catalog. Публичный viewer остаётся
прежним; новый runtime подключён только в админском каталоге сетов.

Исправлены:
- Вращение мышью вверх/вниз и сохранение угла при смене вещи.
- Кеш частей GLB по содержимому: новый ID задания не вызывает повторного
  скачивания неизменённого тела и вещей. Кеш ограничен 192 MiB.
- Отмена устаревшей загрузки при следующем выборе, до завершения старого запроса.
- Повторное декодирование текстур временным материалом GLTFLoader.
- Скрытие выбранного меша из-за старого имени материала в extras.
- Сопоставление исходных имён костей с именами, очищенными GLTFLoader.
- Чтение реальных attachment, loop, activity и additive-флагов из моделей Dota.
- Выбор ACT_DOTA_LOADOUT/ACT_DOTA_IDLE вместо зацикленного loadout_spawn.
- Additive-клипы: композиция при новом экспорте и корректный режим для старых GLB.
- Взвешенные точки крепления с несколькими костями и ignoreRotation.

Проверена подготовка ресурсов в dota-loadout, upstream commit:
https://github.com/justkiddingxd/dota-loadout/tree/3c09d200391cf19db14705dbaca0d6c544dae670

Для старых GLB админка получает небольшие метаданные из исходных VPK. Они
сохраняются в cache/viewer-metadata. Если у GLB сохранён скелет, но отсутствуют
клипы, сервер восстанавливает основные анимации из оригинальной модели; источник
анимаций не рисуется вторым телом. Переэкспорт всей геометрии каталога для этого
не требуется. Исходные VPK/assetDirectories должны быть доступны серверу.

GLB без скелета и весов требует полного переэкспорта: восстановить веса из одной
геометрии безопасно нельзя. Первая загрузка также зависит от размера GLB и
скорости соединения; кеш ускоряет следующие изменения, а не отменяет передачу
первого файла. Некоторые операторы частиц и шейдерные особенности остаются
ограничениями используемой библиотеки.

CI/автодеплой пересоберёт asset-bridge и viewer. Изменений workflow/.NET setup
в этом архиве нет. Ключи R2 и игровые архивы в патч не входят.

Проверки: 597 JS-тестов, компиляция native bridge и тест сохранения GLB chunks.
На исходной модели Spectre извлечены 4 attachment и 31 последовательность;
восстановлены 12 основных клипов. Chromium-проверка с настоящим HTTP-сервером
подтвердила восстановление меню анимаций, выбор idle_anim, вертикальную камеру,
смену видимого меша, попадание в точку кости Head.1 после очистки имени, отмену
старого запроса и отсутствие повторной загрузки неизменённого тела.
Storm Spirit со скриншотов не проверен на точном исходном GLB/пакете пользователя;
совпадение всех его материалов и эффектов с игрой этим тестом не подтверждено.
