# Общий пьедестал и исправление выбора стойки

Объединённый архив включает пьедестал и последующие исправления Native_Resources_FIX. Применить поверх Admin_Viewer_Attachments_Loading_Followup.

hero-pedestal.glb расположен в корне проекта, включается в пакет Windows и загружается новым вивером админки для каждого героя. Это оригинальная круглая каменная подставка по форме референса, а не извлечённая модель Valve. Ресурс самодостаточный, без внешних текстур; около 49 КБ. Повторная загрузка в пределах вивера использует кеш. Масштаб подстраивается под высоту героя, верх совпадает с его исходной плоскостью земли. Парящие герои сохраняют высоту своей анимации. Камера вмещает и героя, и подставку. На R2 повторно выгружать каталог не требуется.

Earthshaker: автоматический выбор стойки не выбирает effigy/statue/debut/spawn при наличии обычной анимации; меню по-прежнему позволяет выбрать их вручную. Исправлено и последующее переключение стойки в интерфейсе.

Публичный вивер и сборка VPK не изменены. CI упаковывает корневой GLB вместе с приложением. Генератор оригинального ресурса: tools/build-viewer-pedestal.mjs (нужны зависимости npm).

Проверено: 603 теста Node, Chromium — загрузка пьедестала, смена вещей, кеш, камера, анимации и настоящий GLB Spectre. Присланные скриншоты показывают и другие проблемы частиц: их полное устранение этим патчем не заявляется.
