Dota Effect Studio 1.3.1

GitHub:
1. Extract this ZIP and upload its contents to the repository root.
2. The workflow must be at .github/workflows/windows-build.yml.
3. On main/master it starts after a push. For any branch: Actions -> Build Windows app -> Run workflow.
4. After a successful run download DotaEffectStudio-Windows-x64 from Artifacts.

Windows build:
Extract the portable app, run configure-dota.bat, then start-desktop.bat.
Node.js, Electron and both native tools are bundled by Actions.

The ZIP contains source code. Windows binaries are built by Actions.
