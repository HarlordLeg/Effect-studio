Dota Effect Studio — веб-студия и локальное приложение для Windows, в которых собираются косметические моды Dota 2. Выбери предметы и эффекты в каталоге, посмотри героя в 3D, перекрась что нужно и получи один готовый VPK. Сборка использует ресурсы установленной игры, поэтому всё в пакете взято из самой Dota.

> [!NOTE]
> Проект активно развивается. 3D-просмотр помогает настроить образ, но не гарантирует полного совпадения с игровым клиентом. Готовый мод всегда проверяй в Dota.

## Режимы студии

Сайт открывается на английском; для русского добавь к адресу `?lang=ru`. Главная страница — студия эффектов; **«Сет»**, **«Косметика»** и **«Погода»** переключаются кнопками вверху страницы.

| Режим | Для чего |
|---|---|
| **Твой эффект** (главная) | Герой, предмет, твой эффект: привязать поддерживаемые эффекты к предметам и покрасить их |
| **Сет** | Полный образ: вещи из разных комплектов, стили, арканы, персоны и кинетические самоцветы для одного или нескольких героев |
| **Косметика** | Глобальная косметика: варды, курьеры, скины HUD, комментаторы, эмблемы, музыка, ландшафты |
| **Погода** | Погодные эффекты поверх выбранного ландшафта |

## Что можно сделать

**Образ**
- Выбрать предметы из разных комплектов и собрать одну корзину для нескольких героев.
- Использовать поддерживаемые арканы, стили, персоны и кинетические самоцветы. Доступность зависит от каталога и совместимости ресурсов.
- Рассмотреть героя в 3D с вещами, эффектами и доступными анимациями.

**Цвет**
- Перекрасить предмет, базу героя, эффекты, способности и иконки. У каждого эффекта может быть свой цвет.
- Изменения видны в 3D сразу, без подтверждения; **«Сравнить с оригиналом»** показывает разницу.

**Сборка**
- Собрать VPK с любым именем от `pak01_dir.vpk` до `pak99_dir.vpk`.
- Сборка с ландшафтом или атаками эмблем приходит ZIP-архивом с `INSTALL.txt` и отдельным файлом карты.

Возможности тестовой студии могут отличаться от основного сайта. Экспериментальные функции публикуются отдельно от общих исправлений сборщика.

## Быстрый старт

1. Открой [dota-studio.lol](https://dota-studio.lol/?lang=ru) или локальное приложение и выбери героя.
2. Выбери вещи в нужных слотах. Новая вещь заменяет предыдущую в том же слоте.
3. При необходимости добавь эффекты. Чтобы поменять цвет, нажми **«Перекрасить»** под предметом; для тела используй слот **«База героя»**.
4. В **«Корзине»** выбери **«Имя VPK»** и нажми **«Собрать VPK»**.
5. Когда сборка готова, нажми **«Скачать VPK»**.
6. Проверь результат в Dota 2. Сохраняй исходные моды отдельно, чтобы можно было вернуться к предыдущей сборке.

> [!TIP]
> Номер VPK меняет только имя пакета, а не пути внутри него. Если несколько модов заменяют один ресурс, результат зависит от порядка загрузки пакетов.

## Перекраска

В окне перекраски выбери, что менять — **«Предмет»**, **«Эффекты»**, **«Способность»** или **«Иконка»**, — и режим:

| Режим | Результат |
|---|---|
| **Сохранить детали** | Меняет цвет с сохранением светлых граней и тёмных деталей исходной цветовой карты |
| **Тонировать** | Умножает исходный цвет на выбранный; тёмные области могут остаться тёмными |
| **Покрасить всю поверхность** | Красит в том числе очень тёмные участки; вид может заметно отличаться от оригинала |

Эффекты можно красить все сразу или по одному. **«Включая связанные части»** переносит цвет и на зависимые части эффекта. Часть свечения задаётся материалами или частицами и настраивается отдельно; карты нормалей и технические маски — не обычные цветовые текстуры.

## Сохранённые сборки

Панель **«Сохранённые сборки»** над корзиной хранит работу в браузере: **«Сохранить»**, **«Сохранить копию»**, **«Загрузить»** и **«Удалить»**. Загруженную сборку можно менять и собирать заново. Сборки хранятся локально в этом браузере и сами в другой браузер или на другой компьютер не переезжают.

## Локальное приложение

Официальные сборки публикуются через [GitHub Actions](https://github.com/HarlordLeg/Effect-studio/actions). Сборка для Windows распространяется как `DotaEffectStudio-Windows-x64`.

Сборщику нужна установленная Dota 2 и доступ к её игровым архивам:

1. Укажи путь к игре через `configure-dota.bat`.
2. Запусти `start-local.bat` (или `start-desktop.bat` — для отдельного окна).
3. Открой `http://127.0.0.1:8787`.

> [!WARNING]
> Не добавляй в репозиторий игровые архивы, готовые пользовательские VPK, секреты сервера или приватные конфигурации.

## Разработка

Раздел для владельца проекта и разработчиков с разрешением на работу с кодом. Условия использования исходников — в [LICENSE](LICENSE).

**Требования:** Windows x64, Node.js 24, .NET SDK 10, установленная Dota 2.

```powershell
npm install
npm run build:viewer
.\build-patcher.bat
.\build-assets.bat
.\configure-dota.bat
npm start
```

Сервер по умолчанию слушает порт `8787`. Другие полезные команды:

| Команда | Что делает |
|---|---|
| `npm run desktop` | Запускает оболочку Electron |
| `npm run doctor` | Проверяет патчер и каталог на текущем конфиге |
| `npm run db:import` | Переносит JSON каталога и статистики в SQLite (`data/integration.sqlite`); `-- --every 60` — раз в час |
| `npm test` | JavaScript-тесты (`node --test tests/*.test.mjs`) |
| `node tools/build-native.mjs patcher` | Прогоняет нативные C#-регрессии и собирает патчер |
| `node tools/package-windows.mjs` | Собирает портативную папку `dist/DotaEffectStudio` |

Успешные тесты не заменяют проверку готового мода в игре. Фиксированное число тестов здесь не указано: актуальный результат смотри в CI.

## Ограничения и сообщения об ошибках

- Браузерная симуляция поддерживает не все операторы частиц, материалы и игровые сценарии.
- Сложные скелеты, физика ткани, превращения и зависимые модели могут требовать отдельного профиля совместимости.
- Некоторые эффекты или модели могут отображаться неправильно даже при успешной сборке VPK.
- После обновления Dota 2 может потребоваться обновление экспортированных данных, кеша или патчера.

Если сборка не удалась, ошибка появляется под кнопкой **«Собрать VPK»** вместе с кнопкой **Bug report**. В сообщении укажи героя, точные названия вещей и стилей, приложи скриншот или видео; при ошибке сборки — полный текст ошибки; если проблема видна только в игре — ещё и собранный VPK. Не отправляй токены, пароли и приватные конфигурации.

| Проблема | Что проверить |
|---|---|
| Локальная страница не открывается | Запуск сервера и сообщения консоли |
| Порт занят | Нет ли второго экземпляра приложения |
| Не найдена модель | Путь к игре, наличие ресурса и актуальность данных каталога |
| Ошибка CRC | Обновление игры; при необходимости проверь целостность игровых файлов |
| В браузере и в игре разный результат | Ограничения симуляции, анимации, привязки частиц и материалы |
